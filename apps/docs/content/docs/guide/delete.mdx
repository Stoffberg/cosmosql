## Deleting Documents

Deleting documents in CosmosDB requires careful consideration of performance, data integrity, and business requirements. This guide covers hard deletes, soft deletes, and best practices.

### Delete Single Document

The basic `delete` operation removes a document permanently:

```typescript
await db.users.delete({
  where: {
    id: 'user_123',
    email: 'john@example.com' // Partition key required
  }
});
```

**Important:** Deletion is permanent and cannot be undone. Always ensure you have the partition key in the `where` clause—this is enforced at compile time.

### Soft Delete Pattern

Instead of permanently deleting documents, consider marking them as deleted:

```typescript
// Instead of deleting, mark as inactive
await db.users.update({
  where: { id: 'user_123', email: 'john@example.com' },
  data: {
    isActive: false,
    deletedAt: new Date()
  }
});

// Query only active users
const activeUsers = await db.users.findMany({
  partitionKey: 'tenant_123',
  where: {
    isActive: true
    // This excludes "deleted" users
  }
});
```

**Why Soft Delete?**
- **Data Recovery:** Can restore deleted data
- **Audit Trail:** Keep history of what was deleted and when
- **Referential Integrity:** Other documents can still reference deleted items
- **Analytics:** Analyze deleted data patterns

### Implementing Soft Delete

Here's a complete soft delete implementation:

```typescript
// Define schema with soft delete fields
const users = container('users', {
  id: field.string(),
  email: field.string(),
  name: field.string(),
  // ... other fields
  isDeleted: field.boolean().default(false),
  deletedAt: field.date().optional(),
  deletedBy: field.string().optional()
}).partitionKey('email');

// Helper functions
async function softDeleteUser(id: string, email: string, deletedBy: string) {
  return await db.users.update({
    where: { id, email },
    data: {
      isDeleted: true,
      deletedAt: new Date(),
      deletedBy
    }
  });
}

async function restoreUser(id: string, email: string) {
  return await db.users.update({
    where: { id, email },
    data: {
      isDeleted: false,
      deletedAt: null,
      deletedBy: null
    }
  });
}

// Query excluding soft-deleted items
async function findAllUsers(partitionKey: string) {
  return await db.users.findMany({
    partitionKey,
    where: {
      isDeleted: false
    }
  });
}

// Query including soft-deleted items (admin view)
async function findAllUsersIncludingDeleted(partitionKey: string) {
  return await db.users.findMany({
    partitionKey,
    // No isDeleted filter
  });
}

// Permanent delete (use with extreme caution)
async function hardDeleteUser(id: string, email: string) {
  return await db.users.delete({
    where: { id, email }
  });
}
```

### Soft Delete Best Practices

**1. Use Expiration Time**

Automatically clean up old soft-deleted items:

```typescript
async function cleanupOldSoftDeletes() {
  const thirtyDaysAgo = new Date();
  thirtyDaysAgo.setDate(thirtyDaysAgo.getDate() - 30);

  const deletedUsers = await db.users.findMany({
    enableCrossPartitionQuery: true,
    where: {
      isDeleted: true,
      deletedAt: { lt: thirtyDaysAgo }
    }
  });

  // Permanently delete old soft-deleted items
  for (const user of deletedUsers) {
    await db.users.delete({
      where: { id: user.id, email: user.email }
    });
  }
}
```

**2. Track Who Deleted**

```typescript
async function deleteUser(userId: string, email: string, deletedByUserId: string) {
  // Log the deletion
  await db.auditLogs.create({
    data: {
      id: `audit_${Date.now()}`,
      action: 'USER_DELETED',
      userId,
      performedBy: deletedByUserId,
      timestamp: new Date()
    }
  });

  // Soft delete the user
  await db.users.update({
    where: { id: userId, email },
    data: {
      isDeleted: true,
      deletedAt: new Date(),
      deletedBy: deletedByUserId
    }
  });
}
```

### Cascade Delete Pattern

When deleting a parent document, you may need to delete related documents:

```typescript
async function deleteUserWithRelatedData(userId: string, email: string) {
  // Find all related posts
  const posts = await db.posts.findMany({
    partitionKey: userId,
    where: {
      // No filter to get all posts
    }
  });

  // Delete all posts
  for (const post of posts) {
    await db.posts.delete({
      where: { id: post.id, userId }
    });
  }

  // Delete user comments
  const comments = await db.comments.findMany({
    partitionKey: email,
    where: {
      authorEmail: email
    }
  });

  for (const comment of comments) {
    await db.comments.delete({
      where: { id: comment.id, authorEmail: email }
    });
  }

  // Finally, delete the user
  await db.users.delete({
    where: { id: userId, email }
  });
}
```

**Note:** CosmosDB doesn't support foreign key constraints or cascade deletes at the database level. You must handle this logic in your application code.

### Batch Delete Operations

CosmosDB doesn't have a built-in batch delete API. You need to delete documents individually:

```typescript
async function deleteManyPosts(postIds: string[], userId: string) {
  const deletePromises = postIds.map(id => 
    db.posts.delete({
      where: { id, userId }
    })
  );

  await Promise.all(deletePromises);
}
```

<Callout type="warning" title="Rate Limiting">

Batch deletions can hit rate limits quickly. Consider implementing backoff logic:

```typescript
async function deleteManyWithBackoff(postIds: string[], userId: string) {
  for (const id of postIds) {
    try {
      await db.posts.delete({ where: { id, userId } });
      await new Promise(resolve => setTimeout(resolve, 10)); // Small delay
    } catch (error) {
      if (error.code === 429) {
        // Rate limited, wait longer
        await new Promise(resolve => setTimeout(resolve, 1000));
        // Retry this item
        await db.posts.delete({ where: { id, userId } });
      } else {
        throw error;
      }
    }
  }
}
```

</Callout>

### Delete by Query

There's no built-in "delete where" operation in CosmosDB. You must:

1. Query for documents matching criteria
2. Delete each one individually

```typescript
async function deleteOldPosts(cutoffDate: Date) {
  // Find old posts
  const oldPosts = await db.posts.findMany({
    enableCrossPartitionQuery: true,
    where: {
      createdAt: { lt: cutoffDate },
      isPublished: false
    }
  });

  // Delete each post
  for (const post of oldPosts) {
    try {
      await db.posts.delete({
        where: { id: post.id, userId: post.userId }
      });
    } catch (error) {
      console.error(`Failed to delete post ${post.id}:`, error);
    }
  }
}
```

### Error Handling

```typescript
try {
  await db.users.delete({
    where: { id: 'user_123', email: 'john@example.com' }
  });
} catch (error) {
  if (error.code === 404) {
    // Document not found
    console.error('User not found');
  } else if (error.code === 429) {
    // Rate limit exceeded
    console.error('Rate limit exceeded, please retry');
  } else {
    console.error('Failed to delete user:', error);
  }
}
```

### Performance Considerations

**1. Always Include Partition Key**

```typescript
// ✅ Good: Includes partition key (fast, ~1 RU)
await db.users.delete({
  where: { id: 'user_123', email: 'john@example.com' }
});
```

**2. Batch Delete Within Partition**

```typescript
// For better performance, group deletions by partition
async function deletePostsByPartition(postIds: string[], userId: string) {
  await Promise.all(
    postIds.map(id => db.posts.delete({ where: { id, userId } }))
  );
}
```

**3. Use Soft Delete for Frequent Deletions**

Hard deletes are expensive if done repeatedly. Soft deletes allow you to batch hard deletes later:

```typescript
// Mark as deleted immediately (fast)
await db.users.update({
  where: { id: 'user_123', email: 'john@example.com' },
  data: { isDeleted: true, deletedAt: new Date() }
});

// Batch permanent deletion later (background job)
setInterval(async () => {
  await cleanupOldSoftDeletes();
}, 60 * 60 * 1000); // Run every hour
```

### Common Patterns

**Pattern: Logical Delete**

```typescript
// Mark as archived instead of deleted
await db.posts.update({
  where: { id: 'post_1', userId: 'user_123' },
  data: {
    status: 'archived',
    archivedAt: new Date()
  }
});
```

**Pattern: Recycle Bin**

```typescript
async function moveToRecycleBin(postId: string, userId: string) {
  // Copy to recycle bin
  const post = await db.posts.findUnique({
    where: { id: postId, userId }
  });

  await db.recycleBin.create({
    data: {
      id: `bin_${postId}`,
      deletedItemId: postId,
      deletedItemType: 'post',
      deletedItemData: post,
      deletedAt: new Date()
    }
  });

  // Remove from original location
  await db.posts.delete({
    where: { id: postId, userId }
  });
}

async function restoreFromRecycleBin(itemId: string) {
  const binItem = await db.recycleBin.findUnique({
    where: { id: itemId }
  });

  if (binItem.deletedItemType === 'post') {
    await db.posts.create({
      data: binItem.deletedItemData
    });
  }

  await db.recycleBin.delete({ where: { id: itemId } });
}
```

**Pattern: Scheduled Deletion**

```typescript
// Attach expiration timestamp at creation
const post = await db.posts.create({
  data: {
    id: 'post_123',
    userId: 'user_123',
    title: 'Temporary Post',
    content: 'This will be deleted in 30 days',
    expiresAt: new Date(Date.now() + 30 * 24 * 60 * 60 * 1000)
  }
});

// Background job to clean up expired items
setInterval(async () => {
  const expired = await db.posts.findMany({
    enableCrossPartitionQuery: true,
    where: {
      expiresAt: { lt: new Date() }
    }
  });

  for (const post of expired) {
    await db.posts.delete({
      where: { id: post.id, userId: post.userId }
    });
  }
}, 60 * 60 * 1000); // Check every hour
```
